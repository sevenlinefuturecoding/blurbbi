# Blurbi roadmap

Build order (from the user):

1. [ ] Auth + onboarding (email/password, auto-confirm; username, display name, bio, emoji avatar)
2. [ ] Drops + Stream (compose with live counter + emoji picker, feed)
3. [ ] Self page (profile with Drops + follower counts)
4. [ ] Engagement (Spark, Echo, Relay, Pass — one per user per Drop, no self-engagement)
5. [ ] Home tabs (Blurbing Now strip of 5 viral, For You heat-ranked, Orbit)
6. [ ] Hall of Blurbs (top 50 Drops, last 7 days)
7. [ ] Safety (report, hide, mute)

Design: minimal, whitespace, rounded corners, light/dark, Framer Motion, mobile-first bottom nav.
